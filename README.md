# Vesta Agent — releases

Download builds of **Vesta Agent** (formerly *My Agent*) by **Persian Studio**.

This repository only hosts the installers and update files. The source code is private.

## Download

Get the latest version from the **[Releases page](https://github.com/SOBi-123/vesta-agent-releases/releases/latest)**:

| Platform | File |
|---|---|
| Windows 10/11 | `...-windows-x64-setup.exe` |
| Windows 7/8 | `...-windows7-8-legacy-setup.exe` |
| Linux (Debian/Ubuntu) | `...-linux-amd64.deb` |
| Linux (any) | `...-linux-x86_64.AppImage` |
| Android | `...-android.apk` |

Check a download against `SHA256SUMS.txt` (for example `sha256sum -c SHA256SUMS.txt --ignore-missing`).

The apps update themselves from `latest.json` in the latest release.
