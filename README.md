## Capabilities

### Everything an assistant should do.
One app, powerful agents, and no servers of ours in between.

| | |
|---|---|
| **Voice calls** | Talk naturally and hear spoken replies. Share your screen mid-call and ask what is wrong. |
| **Screen vision** | With your permission the agent sees your screen, explains it and helps you fix it. |
| **Phone control** | The agent taps, types and navigates on Android, even without a computer. |
| **Multi-agent group chat** | Put specialised agents in one room and let them split the work. |
| **Memory stored locally** | Smart memory that lives only on your device. View, edit or wipe it at any time. |
| **Multi-key failover** | Add several API keys per agent. When one runs out, the next one continues the same task. |
| **Telegram** | Connect your own bot or personal account and schedule messages. |
| **Proxy for Iran** | Real HTTP and SOCKS5 proxy per service, with a built-in step-by-step guide. |
| **Offline mode** | Run entirely on your computer with Ollama. Nothing leaves the machine. |
| **Privacy first** | No accounts and no cloud database. Keys are encrypted on your device. |

### First-run setup
1. Get a free key from [Google AI Studio](https://aistudio.google.com/apikey) or [OpenRouter](https://openrouter.ai/keys), or run models offline with Ollama.
2. Paste it in **Settings > Keys**. Add several for failover.
3. In Iran, add a proxy in **Settings > Proxy**, for example `127.0.0.1:10808` from v2rayN or NekoBox, and press **Test**.

## FAQ

### Questions, answered.

<details><summary>How do I get help or report a bug?</summary>Message our support bot on Telegram, <a href="https://t.me/VestaAgentSupportBot">@VestaAgentSupportBot</a>. Send a description, screenshots or a voice message and you get a ticket number. Replies arrive in the same chat.</details>
<details><summary>Is Vesta Agent free?</summary>Yes. The app is free. You use your own AI key, for example a free Gemini or OpenRouter key, or run models offline with Ollama.</details>
<details><summary>Where is my data stored?</summary>Only on your own device: chats, memory, agents, settings and encrypted keys. There is no Vesta server or online database.</details>
<details><summary>Does it work in Iran?</summary>Yes. Add a proxy in Settings, for example the local port from v2rayN or NekoBox, and choose which services use it. A built-in guide shows each step.</details>
<details><summary>Which AI models does it support?</summary>Gemini, OpenRouter, OpenAI-compatible providers and local models through Ollama.</details>
<details><summary>Will it update automatically?</summary>Yes. It checks quietly at launch and only shows a window when a new version is available. If you have 1.3, install 1.5.0 manually once, because the update address changed.</details>

## Privacy

### Your data never leaves home.
- No Vesta servers and no online database. Chats, memory and settings live on your device.
- API keys are encrypted locally. Passwords, keys and card details are never saved to memory.
- Only the message you send goes to the AI provider whose key you added. With Ollama, nothing leaves at all.
- A visible indicator is always on while the microphone or screen sharing is active.

## Verify (SHA256)
Download [SHA256SUMS](https://github.com/Vesta-Agent/vesta-agent-releases/releases/latest/download/SHA256SUMS) next to your file, then run `sha256sum -c SHA256SUMS --ignore-missing` on Linux or `Get-FileHash <file> -Algorithm SHA256` on Windows.
